# Types of dependencies
dependencies -> which are used to run the application
devDependencies –> packages only needed during development
other two are optionalDependencies, peerDependencies(for library )
**Important** if we don;t mention --save -dev or -D by default it will go under dependencies

tsc - Typescript Compilation (it reads our tsconfig filr and compile typescript (src app.ts  --> dist app.js))
